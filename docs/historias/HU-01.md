# HU-01 — Consulta de aforo en tiempo real

## Historia de usuario

Como **turista**, quiero **consultar el nivel de aforo actual de un sitio turístico (Bajo, Moderado o Alto)**, para **decidir si lo visito ahora o prefiero esperar y evitar aglomeraciones**.

**INVEST:** Independiente (solo necesita el sensor, que se simula), Negociable (umbrales y presentación ajustables), Valiosa (evita aglomeraciones), Estimable, Pequeña (una sola consulta), Testeable (tabla de casos).

## Reglas confirmadas (tabla de pruebas del equipo)

- La capacidad máxima y la ocupación actual del sitio las informa un sensor externo (`SiteSensorInterface`).
- Casos confirmados: ocupación 30 y 40 con capacidad 100 → **Bajo**; 60 y 75 → **Moderado**; 90 → **Alto**.
- Ocupación mayor a la capacidad (120 con capacidad 100) → **Error** (`InvalidArgumentException`).
- Sensor no disponible → `RuntimeException`, que el controller responde con HTTP 503.

## Estado en el código

Ya existen `AforoService`, `SiteSensorInterface`, `HttpSiteSensor` (registrado en `AppServiceProvider`), `SitioAforoController` y `ConsultarAforoIntegracionTest`. El código actual clasifica: Bajo hasta 50 %, Moderado hasta 80 %, Alto por encima. Es el patrón de referencia del proyecto.
