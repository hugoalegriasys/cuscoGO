# HU-02 — Registrar reseña

## Historia de usuario

Como **turista**, quiero **registrar una reseña de un sitio turístico con una calificación de 1 a 5 y un comentario, y ver el promedio de calificaciones del sitio**, para **compartir mi experiencia y ayudar a otros visitantes a decidir**.

**INVEST:** Independiente (no depende de otra HU), Negociable (campos y presentación ajustables), Valiosa (aporta opinión a otros turistas), Estimable, Pequeña (validar, guardar y promediar), Testeable (tabla de casos).

## Reglas confirmadas (tabla de pruebas del equipo)

- `validarCalificacion`: devuelve `true` para 1 a 5 y `false` para 0 y 6. **Devuelve booleano; no lanza excepción.**
- `validarComentario`: devuelve `true` si el texto tiene contenido y `false` si está vacío o solo tiene espacios. **Devuelve booleano.**
- `calcularPromedioCalificaciones`: promedio de la lista. Una lista vacía devuelve `0`.

## Tareas técnicas (independientes)

| # | Capa | Tarea |
|---|---|---|
| T1 | Base de datos | Migración de la tabla `resenas` *(campos por confirmar, ver P4)* |
| T2 | Servicio | `ResenaService` con `validarCalificacion`, `validarComentario` y `calcularPromedioCalificaciones` |
| T3 | API | `POST /api/sitios/{id}/resenas` (valida con el servicio: 201 si es válida, 422 si no) y `GET /api/sitios/{id}/resenas` (lista y promedio) |
| T4 | Pantalla *(solo si el equipo confirma pantalla)* | Formulario con estrellas y comentario, y lista de reseñas con el promedio |
| T5 | QA | Pruebas unitarias del servicio y de integración de los endpoints |

## Pruebas unitarias (backend, T2)

| Método a probar | Datos de entrada | Resultado esperado |
|---|---|---|
| `validarCalificacion()` | 5 | true |

## Pendientes de confirmar (el agente debe preguntar, no decidir)

- **P1.** Comentario: ¿hay longitud mínima o máxima? La tabla solo exige que no esté vacío.
- **P2.** Promedio: ¿se redondea y a cuántos decimales? (por ejemplo, [5, 4, 4] da 4.333…)
- **P3.** Calificación: ¿qué pasa con valores no enteros (4.5) o no numéricos? La tabla no los cubre.
- **P4.** ¿Qué datos guarda una reseña (sitio, calificación, comentario, fecha, usuario)? ¿Se guarda en base de datos real o con datos simulados?
- **P5.** Cuando la validación devuelve `false`, ¿qué mensaje y código HTTP debe recibir el turista?
